# Assets

Use this folder as the single drop location for website assets.

- Put future logos, photos and other image files directly in `assets/`.
- Reference them from pages as `/skills-revolution/assets/<filename>`.
- Shared front-end files are also kept here so the standalone GitHub Pages build has one predictable asset location.

The current website did not contain standalone image files; its decorative visuals were CSS-generated. Existing shared CSS/JS/navigation assets are now mirrored here and the page wrappers reference this folder.
